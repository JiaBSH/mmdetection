# 2.5×统一滑窗参数网格实验设计

## 目标

在 `test2_5_t1` 的4张2.5×图像上，使用完全一致的参数网格分别评估 COCO Segm mAP、COCO Box mAP、Precision、Recall、F1-score 和 IoU。实验用于参数敏感性分析，不表述为独立验证集上的无偏调参。

## 数据与固定条件

- 图像：`2p5x_00016.png` 至 `2p5x_00019.png`
- 标注：`data/syn_multimag/coco_rotation/test2_5_t1/instances_test.json`
- 模型、权重、阈值、批大小、合并规则及 COCO `max_dets` 与现有单图预实验完全一致
- 每个参数组合均处理4张图；先计算单图指标，再对4张图取算术平均
- 不保存预测可视化、中间掩膜或几何分析结果，仅保存紧凑 JSON、汇总表和最终热力图

## 第一阶段：统一粗网格

- 窗口尺寸（px）：`128, 160, 192, 224, 256, 320, 400, 512`
- 交叠率：`0.05, 0.10, 0.15, 0.20, 0.25, 0.30, 0.40, 0.50`
- 规模：8×8×4，共256次单图推理

六项指标必须由同一批64个参数组合生成，并使用相同的坐标顺序和色图。当前单图5×5结果仅作为预实验，不与四图均值混合。

## 峰值与扩展规则

六项指标分别寻找最大值，不构造复合指标。

1. 若任一指标最大值位于窗口尺寸或交叠率边界，则不得宣称已找到最终参数。
2. 按该边界方向为整个统一网格增加参数档位，六项指标同步扩展。
3. 若最大值不在边界，且上下左右相邻格点均不高于该点，则记为内部候选峰值。
4. 若相邻参数差异很小，则报告为稳定平台，不通过裁剪坐标制造峰值。

## 第二阶段：统一细化网格

粗搜索完成后，取六项指标候选峰值在两个坐标轴上的并集范围，四周各保留至少一个档位。细化时窗口步长为32 px、交叠率步长为0.05；六项指标继续共用完全相同的网格。若细化峰值再次落到边界，则按相同规则扩展。

## 输出与验收

- 每个单图、每个参数组合一个 JSON，共256个粗搜索 JSON
- 一份包含四图均值及离散程度的 CSV/JSON 汇总
- 六项独立黄橙色热力图和一张2×3组合图，坐标规格一致
- 自动检查：参数组合无缺失/重复、每格包含4张图、指标均为有限值、图表只读取真实结果
- 只有通过边界检查的指标才报告内部最优参数；其余指标报告继续扩展或平台趋势
